# Spark Academy™ — Website

Static marketing site for Spark Academy™: a literacy platform for educators, parents, and global partners.

## Pages
- `index.html` — Home
- `about-us.html` — About Us
- `about-spark-academy.html` — About Spark Academy™
- `how-it-works.html` — How It Works
- `resources.html` — Resources
- `get-started.html` — Get Started
- `contact.html` — Contact

## Stack
Plain HTML/CSS/JS. No build step — deploys as-is to Vercel or any static host.

## Before launch
- Replace placeholder copy, statistics, team names, and email addresses with real client content.
- Wire the forms on `get-started.html` and `contact.html` to a real endpoint (e.g. Formspree, a serverless function, or the client's CRM) — they currently point at `#`.
- Swap placeholder resource links on `resources.html` for real files.
- Fonts (Fraunces, Work Sans) load from Google Fonts via `<link>` tags in each page `<head>`.
